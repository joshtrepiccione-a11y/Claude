# Official American Legion brandmark files go here

Copy the untouched official PNG files from `American-Legion-Brandmark.zip` into this folder using these exact names:

| File name | Which official file | Where the site uses it |
| --- | --- | --- |
| `american-legion-brandmark-primary-rgb.png` | Primary brandmark, RGB, transparent PNG | Site header (white background) |
| `american-legion-brandmark-secondary-white.png` | Secondary one-color white brandmark, PNG | Footer (Emblem Blue background) |
| `american-legion-brandmark-secondary-black.png` | Secondary one-color black brandmark, PNG | Reserved for future use |
| `american-legion-brandmark-complex-background-rgb.png` | Tertiary complex-background brandmark, RGB PNG | Reserved for future use |

Rules the site already follows, and you must keep following:

- Do not open these files in any AI tool. Do not upscale, recolor, trace, redraw, crop, or add effects.
- The site only sets the display height; width scales proportionally. Never stretch.
- The wrapper reserves clear space of half the mark's height on every side, which exceeds the width of the "L" in the brandmark. Verify against the official file at final size.
- The emblem is never used on this public-facing site. Do not add it.
- If a file is missing, the site shows the Post name in Inter text instead. It never draws a substitute mark.

Until the files are copied in, the header and footer show the Post name as text.
